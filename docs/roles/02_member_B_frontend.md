# 👤 팀원 B: 프론트엔드 UI & 대시보드 시각화 (Frontend & Visualization)

> **핵심 미션:** 구글 시트 및 정제 데이터를 바탕으로 사용자가 직관적으로 이해할 수 있는 반응형 웹 대시보드를 디자인하고 구현합니다.

---

## 🚀 개발 완료 상태: 100% 완료 (Production Ready)

현재 프론트엔드 대시보드 코드는 모든 기본 요구사항과 심화 기능(다크 모드, 엑셀 CSV 추출, 지출 랭킹 바 등)까지 완벽하게 구현되어 GitHub Pages 자동 배포 환경에 배포되었습니다.

---

## 🛠️ 적용된 기술 스택
- **프론트엔드 뷰 & 스타일링:** HTML5, Tailwind CSS (반응형 모바일/데스크톱 UI)
- **차트 라이브러리:** Chart.js (월별 수입/지출 비교 바 차트, 카테고리별 도넛 차트)
- **데이터 파싱:** PapaParse (구글 시트 실시간 CSV 원격 스트리밍 파싱)
- **아이콘 및 폰트:** Lucide Icons, Pretendard
- **배포 인프라:** GitHub Actions + GitHub Pages (`.github/workflows/deploy.yml`)
