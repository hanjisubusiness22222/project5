# 👤 팀원 B: 프론트엔드 UI & 대시보드 시각화 (Frontend & Visualization)

> **핵심 미션:** 정제된 회계 JSON 데이터를 바탕으로 사용자가 직관적으로 이해할 수 있는 반응형 웹 대시보드를 디자인하고 구현합니다.

---

## 🛠️ 권장 기술 스택
- **프레임워크 / 빌드 툴:**
  - 옵션 1 (경량/초간단): Vanilla JS + HTML5 + Tailwind CSS (빌드 없이 바로 Pages 배포 가능)
  - 옵션 2 (SPA/확장성): Vite + React + Tailwind CSS
- **차트 라이브러리:**
  - Chart.js (`chart.js`) 또는 Recharts / ApexCharts
- **아이콘 & 폰트:** Lucide Icons / Heroicons, Pretendard

---

## 📋 세부 업무 및 태스크 목록

### 1. 화면 설계 및 레이아웃 와이어프레임
- [ ] 반응형 대시보드 레이아웃 (모바일 / 태블릿 / 데스크톱 최적화)
- [ ] 상단 헤더: 서비스 명칭, 마지막 업데이트 시각, 수동 새로고침 안내/링크

### 2. 핵심 UI 컴포넌트 개발
- [ ] **요약 카드 (KPI Cards):**
  - 총 수입 (금액 + 폰트 컬러: 파란색/초록색)
  - 총 지출 (금액 + 폰트 컬러: 빨간색/주황색)
  - 현재 잔액 (수입 - 지출 잔여금, 카드 강조 디자인)
- [ ] **차트 시각화 영역:**
  - 월별 지출/수입 추이 (막대/라인 복합 차트)
  - 카테고리별 지출 점유율 (도넛/파이 차트)
- [ ] **상세 거래 내역 테이블:**
  - 컬럼: 일자, 구분(수입/지출 태그), 카테고리, 항목명, 금액, 결제수단, 비고
  - 금액 천 단위 콤마 포맷팅 (`100,000원`)
  - 페이지네이션 (10개/20개 단위) 또는 무한 스크롤

### 3. 사용자 인터랙션 & 필터링 기능
- [ ] 기간 선택 필터 (전체 / 이번 달 / 최근 3개월 / 연도별)
- [ ] 구분 필터 (전체 / 수입만 / 지출만)
- [ ] 카테고리 필터 드롭다운
- [ ] 항목명/비고 키워드 검색창
- [ ] CSV/Excel 다운로드 버튼 (선택 사항)

## 💡 개발 팁 (독립 개발 방식)
- 팀원 A의 파이프라인 개발 완료 전까지는 `public/mock_data.json` 파일을 직접 만들어 로컬에서 화면을 구현하고 테스트합니다.
- `fetch('./accounting_data.json')` 형태로 비동기 로드하도록 작성하면, 실제 배포 시 파일명만 맞추면 즉시 연동됩니다.
