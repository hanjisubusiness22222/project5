# 👤 팀원 C: 데이터 규격 & 인프라/보안/QA (Schema & Ops/QA)

> **핵심 미션:** 구글 시트의 입력 규격(데이터 무결성)을 수립하고, GCP 인증 및 GitHub Secrets 보안 설정을 총괄하며, 배포 환경 구축과 최종 품질 검증을 수행합니다.

---

## 🛠️ 담당 영역 및 도구
- **데이터 관리:** Google Sheets (데이터 유효성 검사, 드롭다운, 조건부 서식)
- **클라우드 & 보안:** Google Cloud Platform (GCP Console), GitHub Secrets
- **배포 인프라:** GitHub Pages (Settings, Custom Domain 등)
- **품질 관리:** QA 체크리스트, 매뉴얼 작성 (Markdown)

## 📋 세부 업무 및 태스크 목록

### 1. 구글 시트 데이터 스키마 표준화 & 템플릿 제작
- [ ] 시트 컬럼 규격 정의 (1행 헤더):
  | 컬럼명 | 필수 여부 | 데이터 타입 | 예시 | 비고 / 유효성 검사 |
  | :--- | :---: | :---: | :---: | :--- |
  | `일자` | O | YYYY-MM-DD | `2026-03-15` | 날짜 형식 강제 유효성 검사 |
  | `구분` | O | 텍스트 (택1) | `수입` / `지출` | 드롭다운 목록 지정 |
  | `카테고리`| O | 텍스트 (택1) | `식비`, `비품`, `교통비` | 드롭다운 목록 지정 |
  | `항목명` | O | 텍스트 | `사무용품 구매` | 자유 텍스트 |
  | `금액` | O | 숫자 | `15000` | 숫자만 입력 허용 (음수 불가) |
  | `결제수단`| X | 텍스트 (택1) | `법인카드`, `계좌이체` | 드롭다운 목록 지정 |
  | `작성자` | X | 텍스트 | `홍길동` | 담당자 입력 |
  | `비고` | X | 텍스트 | `영수증 링크 등` | 추가 메모 |

- [ ] 구글 시트 입력 서식 템플릿 생성 및 팀원 공유

---

### 2. GCP 인증 및 GitHub Secrets 보안 환경 설정
- [ ] **GCP 프로젝트 및 Service Account 생성**
  1. Google Cloud Console에서 새 프로젝트 생성
  2. Google Sheets API 활성화
  3. 서비스 계정(Service Account) 생성 및 키(JSON 형식) 다운로드
  4. 구글 시트 공유 설정에 서비스 계정 이메일을 **뷰어(Viewer)**로 초대
- [ ] **GitHub Secrets 등록 (Repository Settings > Secrets and variables > Actions)**
  - `GCP_SA_KEY`: 서비스 계정 JSON 문자열 전체
  - `SPREADSHEET_ID`: 연동할 구글 시트 고유 ID (URL의 `/d/{ID}/edit` 부분)
  - `SHEET_NAME`: 탭 이름 (기본값: `Sheet1` 또는 `회계장부`)

---

### 3. GitHub Pages 호스팅 설정 및 보안 점검
- [ ] GitHub Pages 배포 설정 활성화 (`GitHub Actions` 소스로 설정)
- [ ] **보안 검토:**
  - 저장소가 Public인 경우 시트 데이터가 외부에 공개되므로, 민감 정보(개인 계좌번호, 주민번호 등)가 시트에 들어가지 않도록 가이드 수립
  - 필요 시 웹 대시보드 진입 시 간단한 패스코드(PIN 번호) 잠금 검토

---

### 4. 통합 테스트 (QA) 및 사용자 가이드 작성
- [ ] **데이터 정합성 테스트:**
  - 시트의 합계와 웹 대시보드 요약 카드의 합계가 정확히 일치하는지 검증
  - 잘못된 날짜나 빈 행 입력 시 파이프라인 에러 여부 테스트
- [ ] **크로스 디바이스 테스트:** 모바일 브라우저(iOS Safari, Android Chrome) 렌더링 확인
- [ ] **문서화:** 시트 작성 요령 가이드 및 장애 대처 방법 문서화
